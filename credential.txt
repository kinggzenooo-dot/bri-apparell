1. SYSTEM OVERVIEW
-----------------------------------------------------------------------------
BRI APPARELL is a full-stack architectural streetwear retail system featuring:
- High-fashion customer storefront (Catalog, Cart, Checkout, Live Tracking)
- Professional Executive Admin Console (admin/ folder)
- Retail Staff Operations Console (staff/ folder)
- Python Flask Unified REST API backend
- Centralized SQL Database (PostgreSQL with SQLite local dev fallback)

3. REQUIRED ENVIRONMENT VARIABLES (.env)
-----------------------------------------------------------------------------
Configure these in your production hosting environment (e.g., Render Dashboard):

- SECRET_KEY
  Cryptographic key used to sign sessions and HMAC tokens.
  Value: (Set a random 32+ character hex string)

- DATABASE_URL
  Standard PostgreSQL connection string.
  Format: postgresql://<user>:<password>@<host>:<port>/<database>
  Note: When deployed on Render or Supabase, Render automatically injects this.
  If unset, system runs on local SQLite (bri_apparel.db).

- PORT
  The listening TCP port. Render sets this automatically (usually 10000 or 5000).
  Default: 5000

- FLASK_ENV
  Mode of operation.
  Value: production

- SUPABASE_URL & SUPABASE_ANON_KEY (Optional)
  Supabase storage / CDN credentials if using Supabase asset hosting.

4. LOCAL INSTALLATION & DEVELOPMENT COMMANDS
-----------------------------------------------------------------------------
# 1. Create Python virtual environment (optional but recommended):
python -m venv venv
venv\Scripts\activate   # On Windows
# source venv/bin/activate # On Linux/macOS

# 2. Install required dependencies:
pip install -r requirements.txt

# 3. Initialize & Seed Database (Automatic on startup or run manually):
python database.py

# 4. Run automated test suite:
python test_system.py

# 5. Start development server:
python app.py

5. RENDER PRODUCTION DEPLOYMENT
-----------------------------------------------------------------------------
A. Create a Web Service on Render connected to this repository:
   - Environment: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app

B. Attach a PostgreSQL Database on Render:
   - In Render, create a PostgreSQL instance: "bri-apparel-db"
   - Copy the "Internal Database URL"
   - Add it to the Web Service Environment Variables as `DATABASE_URL`

C. Add Environment Variables in Render:
   - SECRET_KEY = <generate-random-secret-key>
   - FLASK_ENV  = production

The application will automatically detect PostgreSQL, create tables using
schema.sql, seed initial catalog data, and serve customer, staff, and admin
portals on your Render URL.
